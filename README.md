# Иссиқлик / Мерзнем

Простое статическое приложение для GitHub Pages: считает среднюю температуру за последние
5 суток (120 часов) для Ташкента или любого города Узбекистана/СНГ (данные Open-Meteo, без API-ключа).

- средняя < 8 °C → большая кнопка **ИССИҚЛИК** (узб. «тепло/отопление»)
- иначе → **МЕРЗНЕМ**

## Прогноз начала отопительного сезона
Модель «аналоговых лет»: 16-дневный прогноз погоды, дальше — фактическая погода тех же дат
в каждом из прошлых 10 лет (архив Open-Meteo). Для каждого сценария ищется первый день,
когда средняя за 5 суток < 8 °C:
- **оптимистичный** — самый ранний сценарий (тепло дадут раньше),
- **наиболее вероятный** — медиана,
- **пессимистичный** — самый поздний.
